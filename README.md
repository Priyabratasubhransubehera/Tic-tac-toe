## 🎮 Tic-Tac-Toe Game

This Tic-Tac-Toe Game is a classic two-player strategy game designed to demonstrate logical thinking, control flow, and clean programming practices.
The project focuses on implementing core game mechanics, handling user input efficiently, and ensuring accurate win/draw detection.

Built with simplicity and clarity in mind, this project highlights my ability to transform a basic concept into a fully functional and structured application, making it both beginner-friendly and logically strong.

## ✨ Features

🔁 Two-Player Gameplay (Player X vs Player O)

🧠 Smart Game Logic for win, lose, and draw conditions

🎯 Real-Time Board Updates after each move

🚫 Move Validation (prevents overwriting filled cells)

🏆 Automatic Winner Detection

🤝 Draw Detection when no moves remain

♻️ Game Reset Option (restart without reloading)

📐 Clean & Readable Code Structure
